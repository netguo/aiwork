💢 问题背景：AI 对话的"健忘症"

你每天都在用各种 AI Agent（Claude Code、Cursor、ChatGPT、各种自建 Agent）搜索和解决各种问题。但一个普遍的痛点是：

搜索后的问题没有沉淀，过段时间就忘了。

痛点 1：不同 AI 工具的对话历史互相隔离，无法共享
痛点 2：有价值的发现和结论散落在各处，没有统一沉淀
痛点 3：下次遇到类似问题时，无法回忆之前的解决方案
痛点 4：团队的知识无法通过 AI 对话自动积累

本指南调研了 GitHub 上 109 个相关开源项目，精选 8 个最值得关注的方案，并提供 3 条从简单到完整的自建路径，帮助你构建 AI 对话知识沉淀系统。

🔍 开源方案：8 个精选项目

Mem0

62.2K stars Apache-2.0
Universal Memory Layer for AI Agents
mem0ai/mem0

为 AI 助手提供通用记忆层的开源项目。支持 Claude Code、Cursor、Windsurf 等主流 AI 工具，通过自动提取、存储和召回对话中的关键信息，实现跨会话的持久记忆。

技术栈 Python, FastAPI, PostgreSQL/Redis, Qdrant/ChromaDB
适用场景 希望立即给现有 AI 工具加上记忆能力的用户；需要跨工具共享记忆的场景
部署难度 低 — pip install mem0ai 即可使用

核心亮点

  • 多级记忆架构：短期记忆 + 长期记忆 + 实体记忆
  • 语义检索 + BM25 + 实体图谱混合召回，LoCoMo 基准测试得分 92.5
  • 原生支持 Claude Code / Cursor / Windsurf / LangChain / CrewAI / AutoGen
  • 可自托管（Docker），也提供云端 API
  • 自动从对话中提取事实性记忆，无需手动标注

Khoj

36.1K stars AGPL-3.0
Self-hostable AI Second Brain
khoj-ai/khoj

可自托管的 AI 第二大脑。将你的笔记、文档、对话统一存储和检索，支持桌面、Web、移动端、Obsidian 插件等多平台访问。内置 RAG 引擎和向量检索。

技术栈 Python/Django, PostgreSQL, pgvector, React
适用场景 希望完全自控数据的个人知识管理；需要多平台访问的场景
部署难度 中 — Docker Compose 部署，需配置 PostgreSQL

核心亮点

  • 完全自托管，数据隐私有保障
  • Django + PostgreSQL + pgvector 后端，稳定可靠
  • 支持 Markdown / PDF / Notion / Obsidian 等多种数据源
  • 桌面客户端 + Web + 移动端 + Obsidian 插件全覆盖
  • 内置 AI 对话，可自动关联历史搜索和笔记

Letta (MemGPT)

24.0K stars Apache-2.0
Stateful Agent Framework with 3-Tier Memory
letta-ai/letta

MemGPT 的继任者，提供分层记忆架构的 AI Agent 框架。核心记忆（当前对话）、召回记忆（历史搜索）、归档记忆（长期存储）三层结构，模拟人类记忆机制。

技术栈 Python, PostgreSQL, pgvector, FastAPI
适用场景 需要最深度记忆架构的 Agent 开发；研究型项目
部署难度 中高 — 需理解记忆分层概念，配置 PostgreSQL + pgvector

核心亮点

  • 3 层记忆架构：Core Memory（核心记忆）/ Recall Memory（召回记忆）/ Archival Memory（归档记忆）
  • 基于 PostgreSQL + pgvector，支持 128K 超长上下文
  • Agent 自主决定何时读写记忆，实现自进化
  • 提供 REST API + Python SDK + 可视化界面
  • 源自 UC Berkeley MemGPT 论文，学术基础扎实

Memori

15.7K stars Apache-2.0
Agent-Native Memory with 8-Category Extraction
MemoriLabs/Memori

专为 AI Agent 设计的原生记忆系统。通过 3 层归因模型和 8 类结构化信息提取，将对话中的知识自动分类、存储和召回。原生支持 LangChain。

技术栈 Rust, Python, LangChain, Qdrant
适用场景 使用 LangChain 技术栈的团队；需要结构化知识提取的场景
部署难度 低中 — pip install memori，LangChain 集成只需几行代码

核心亮点

  • 8 类结构化提取：偏好、事实、事件、关系、指令、摘要、上下文、反馈
  • 3 层归因模型：事实层 + 事件层 + 摘要层
  • LoCoMo 基准测试 87% 准确率，仅需 2.8% 上下文窗口
  • Rust 核心引擎，高性能低延迟
  • 原生 LangChain / LangGraph 集成，即插即用

memvid

16.1K stars MIT
Video-Based Memory, No Vector DB Needed
memvid/memvid

创新性地将记忆编码为视频文件，无需向量数据库即可存储和检索海量记忆。通过视频压缩技术实现极低成本的长期记忆存储。

技术栈 Python, OpenCV, FAISS（可选）
适用场景 不想维护向量数据库的场景；需要超低成本存储海量记忆
部署难度 低 — pip install memvid-lib，无需额外基础设施

核心亮点

  • 零依赖：无需 Qdrant / Pinecone / Weaviate 等向量数据库
  • 将记忆编码为 MP4 视频文件，单文件可存百万级记忆
  • OCR + 语义检索混合召回，准确率高
  • 存储成本极低，适合海量长期记忆
  • API 简单：from memvid import MemvidEncoder

EverMind-AI/EverOS

以 Markdown 为核心的便携式记忆系统。所有记忆都以纯文本 Markdown 文件存储，可读性强、可移植、无锁定。支持跨 Agent 共享和版本控制。

技术栈 Python/Node.js, Markdown, 文件系统
适用场景 喜欢 Markdown 工作流的用户；需要版本控制记忆的场景

核心亮点

  • 零数据库依赖，文件系统即存储

🛠 自建方案：3 条路径

方案 A：Mem0 插件式 — 最快上手

直接使用 Mem0 的通用记忆层，5 分钟给现有 AI 工具加上跨会话记忆能力。无需改动现有代码架构。

零代码改动 支持 Claude Code / Cursor 可自托管 1-2 天落地 
from mem0 import Memory
import os

# 初始化（可自托管或用云端）
os.environ["MEM0_API_KEY"] = "your-api-key"
memory = Memory()

# 保存对话记忆
memory.add(
    "用户正在研究 LangChain + LangGraph 作为 Agent 框架，"
    "RAGFlow + LightRAG 作为 RAG 引擎。",
    user_id="netguo",
    metadata={"source": "claude-code", "topic": "tech-selection"}
)

# 召回相关记忆
results = memory.search("团队选了什么 Agent 框架", user_id="netguo")
for r in results:
    print(f"[{r['score']}] {r['memory']}")

方案 B：LangGraph 知识沉淀流水线 — 团队级

基于团队已有 LangChain + LangGraph + RAGFlow + LightRAG 技术栈，构建完整的知识沉淀流水线。5 个节点的 StateGraph 实现捕获→提取→质检→存储→召回的全链路自动化。

复用已有技术栈 8 类知识自动分类 RAGFlow + LightRAG 双存储 1-2 周落地 
from langgraph.graph import StateGraph, END
from typing import TypedDict, List
import json

class SedimentationState(TypedDict):
    raw_dialog: str
    agent_source: str
    extracted_facts: List[str]
    quality_scores: List[float]
    stored_count: int
    recall_context: str

def capture_node(state):
    """捕获 AI 对话内容"""
    return {"raw_dialog": state["raw_dialog"],
            "agent_source": state["agent_source"]}

def extract_node(state):
    """LLM 提取 8 类结构化知识"""
    prompt = f"""从以下对话中提取关键知识，分类为：
    1.偏好 2.事实 3.事件 4.关系 5.指令 6.摘要 7.上下文 8.反馈
    对话: {state['raw_dialog']}
    输出 JSON 格式的知识列表。"""
    # 调用 LLM 提取
    facts = llm_extract(prompt)  # 实际调用 LangChain LLM
    return {"extracted_facts": facts}

def quality_node(state):
    """去重 + 质量评分"""
    facts = state["extracted_facts"]
    # 去重：与已有知识做语义相似度比较
    unique_facts = deduplicate(facts)
    # 质量评分：完整性 + 新颖性 + 可靠性
    scores = [score_fact(f) for f in unique_facts]
    return {"quality_scores": scores, "extracted_facts": unique_facts}

def store_node(state):
    """写入 RAGFlow + LightRAG + 结构化数据库"""
    for fact, score in zip(state["extracted_facts"],
                           state["quality_scores"]):
        if score > 0.6:  # 质量阈值
            ragflow_store(fact)        # 文档级 RAG
            lightrag_insert(fact)      # 图谱级 RAG
            memory_db_save(fact)       # 结构化存储
    return {"stored_count": len(state["extracted_facts"])}

def recall_node(state):
    """下次对话时注入相关记忆"""
    context = memory_search(state["raw_dialog"])
    return {"recall_context": context}

# 构建 LangGraph 工作流
graph = StateGraph(SedimentationState)
graph.add_node("capture", capture_node)
graph.add_node("extract", extract_node)
graph.add_node("quality", quality_node)
graph.add_node("store", store_node)
graph.add_node("recall", recall_node)
graph.set_entry_point("capture")
graph.add_edge("capture", "extract")
graph.add_edge("extract", "quality")
graph.add_edge("quality", "store")
graph.add_edge("store", "recall")
graph.add_edge("recall", END)
app = graph.compile()

方案 C：MCP Memory Server — 全生态统一

构建 MCP（Model Context Protocol）协议的记忆服务，让所有 AI Agent（Claude Code、Cursor、自建 Agent）共享同一记忆库。真正的全生态 AI 知识中枢。

跨 Agent 共享 MCP 标准协议 团队级权限控制 2-4 周落地 
from mcp.server import Server
import asyncio

server = Server("memory-sedimentation")

@server.tool("save_conversation")
async def save_conversation(dialog: str, agent_source: str):
    """保存 AI 对话记忆，自动提取和存储"""
    facts = await extract_facts(dialog)
    for fact in facts:
        await ragflow_store(fact, source=agent_source)
        await lightrag_insert(fact)
        await structured_save(fact, agent_source)
    return {"status": "ok", "saved": len(facts)}

@server.tool("recall_memory")
async def recall_memory(query: str, top_k: int = 5):
    """跨 Agent 召回相关记忆"""
    # 向量召回
    vec_results = await vector_search(query, top_k)
    # 图谱召回
    graph_results = await graph_search(query, top_k)
    # 合并去重 + 重排序
    merged = rerank(vec_results + graph_results)
    return {"memories": merged}

@server.tool("search_by_time")
async def search_by_time(start: str, end: str, keyword: str):
    """按时间范围搜索记忆"""
    results = await time_range_query(start, end, keyword)
    return {"results": results}
